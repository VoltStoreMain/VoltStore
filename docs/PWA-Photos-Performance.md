# VoltStore PWA, Mobile Performance, Local Product Photos

Ветка feature/pwa-performance-photos основана на feature/mobile-first-marketplace (PR #7). Рабочая main не изменена.

## PWA
- Установка через manifest.webmanifest: PNG-иконки 192/512 и ярлыки Каталог, Продать, VoltCheck.
- pwa-client.js предлагает установку только по действиям пользователя; на iPhone показывает инструкцию через меню Поделиться.
- sw.js кэширует только статические UI-файлы, после первой успешной загрузки. Реальные index.html, app.js, live.js, config.js, API, Supabase Auth, Netlify Functions и запросы с Authorization не перехватываются.
- HTML сохраняется без пользовательских параметров query в ключах кэша. Есть офлайн-страница offline.html и ручное применение обновлений.
- PWA требует HTTPS или localhost, одиночный HTML через file:// нельзя установить как полноценное PWA.

## Фотографии
- До 4 собственных фотографий JPG/PNG/WebP/HEIC, до 12 МБ на файл.
- Обработка на устройстве: до 1400 px, JPEG до примерно 950 КБ, исходные EXIF исключаются за счёт отрисовки в Canvas.
- Хранение IndexedDB только на данном устройстве и в данном браузере. Реальной загрузки на сервер нет.
- В локальных черновиках есть превью в каталоге и галерея товара. Можно заменить фотографии и удалить их вместе с черновиком.
- Демо-примеры без пользовательских фотографий сохраняют иллюстрации категорий, не изображают настоящие объявления.

## Производительность
- Задержка рендера поиска 120 мс после ввода, не на каждый символ.
- Ленивое получение обложек из IndexedDB через IntersectionObserver и img loading=lazy.
- URL.createObjectURL очищаются после смены карточки, чтобы не сохранять лишнюю память.
- Офлайн-кэш общих экранов после первой загрузки. Никаких измеренных процентов ускорения без Lighthouse пока не заявляем.

## Ограничения и подготовка к релизу
- Это зависимая цепочка PR #2 → #3 → #4 → #5 → #6 → #7 → новая ветка. Нельзя отдельно объединять в main без проверки.
- Нет реальных универсальных объявлений, платежей, настоящего бронирования или публичного хранения снимков.
- Очистка данных браузера может удалить локальные фото; HEIC поддерживается не везде.
- Нужно проверить установку, офлайн, смену версии и фото на реальном Android Chrome и iOS Safari.
- Провести Lighthouse/Performance (LCP, INP, CLS) на тестовом HTTPS-деплое и сравнить показатели до/после.
- Прежде чем включать реальные фото: серверное хранение с Supabase Storage policies, RLS и модерацией, проверка обработки данных по законодательству Казахстана.
