# VoltGuide: помощник по выбору и проверке товара (экспериментальный релиз)

## Реализовано
- Отдельная адаптивная страница `voltguide.html` для четырёх категорий: смартфоны, ноутбуки, мебель, велосипеды.
- **Бесплатный экспертный режим**: детерминированные рекомендации по 11 проверкам категории, вопросам продавцу и действиям перед оплатой.
- Контекст конкретного объявления через параметры `category`, `ad`, `model`, `price`; данные осмотра читаются из `sessionStorage` того же браузера. Подсказки не являются результатом AI-модели.
- Ссылки на VoltGuide из каталога, карточки б/у смартфона, VoltCheck Universal и VoltPassport.
- Опциональный **генеративный режим** через Netlify Function `/.netlify/functions/voltguide-ai`, **выключен по умолчанию**.

## Что делать с настоящим AI
Режим предназначен для ручного закрытого тестирования, а не немедленного публичного запуска. Без конфигурации функция возвращает 503, запросы к платному провайдеру не отправляются.

Перед запуском:
1. Проверьте юридическое основание и географию обработки данных в Казахстане. Не отправляйте фотографии, личные сообщения и полные IMEI.
2. Определите бюджет, модель и лимиты на запросы. Нужен надёжный серверный лимитер/квота на пользователя — **в прототипе его нет**, поэтому нельзя открывать публичный доступ.
3. В настройках Netlify задайте секреты **только для Functions**, не в `config.js` или `netlify.toml`:
   - `VOLTGUIDE_AI_ENABLED=true` — только после согласования бюджета и проверок.
   - `OPENAI_API_KEY` — отдельный ограниченный ключ проекта.
   - `VOLTGUIDE_AI_MODEL` — проверенное название модели (обязательно).
   - `VOLTGUIDE_SUPABASE_URL` — корректный URL действующего VoltStore Auth.
   - `VOLTGUIDE_SUPABASE_KEY` — publishable/anon ключ действующего проекта.
   - `VOLTGUIDE_ALLOWED_USER_IDS` — запятыми UUID пользователей для закрытого пилота.
4. Протестируйте JWT-проверку на действительном и просроченном токене; не ориентируйтесь только на пользовательские метаданные.
5. Проверьте отсутствие утечки контактов, журналирование, задержки, лимиты затрат и защиту от абьюза.
6. Только затем активируйте AI для ограниченного круга тестовых пользователей.

Сервер вызывает **Responses API** с `store:false`, ограничивает размер запроса и ответа; ключ не попадает в браузер. Текст вопроса проходит базовое маскирование контактов и на клиенте, и на сервере, но это **не гарантирует полного удаления персональных данных**. Внешнюю модель может заинтересовать любая отправленная пользователем информация: предупреждение и явная галочка обязательны.

## Честные ограничения
- Нет поиска по свежим объявлениям, автоматической проверки личности/IMEI или достоверной оценки цены.
- Советы зависят от отметок пользователя, не являются сертификацией товара или гарантией сделки.
- Реальный AI не активирован и не тестировался с платным API.
- Нет production rate limiting, достаточного аудита и реальных тестов DB RLS.
- PR базируется на `feature/voltstore-universal-inspections`, который базируется на `feature/voltpassport-v1`. Не мержить в `main`, пока нет тестов базы и разрешения пользователя.

## Как проверить
```sh
node --test tests/*.test.cjs tests/*.test.mjs
node --check voltguide-core.js
node --check voltguide.js
node --check netlify/functions/voltguide-ai.mjs
```

Ручные сценарии: 4 категории, пустые проверки, критическая проблема, получение контекста через ссылку из объявления, мобильная ширина, копирование вопросов, отключённый AI endpoint.
