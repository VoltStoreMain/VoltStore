# VoltPassport v2 + VoltCheck Universal

## Что реализовано

Временная демонстрация универсального паспорта для **четырёх категорий**: смартфон, ноутбук, мебель, велосипед. Все категории имеют по 11 специализированных проверок. `passport-core.js` — единый, независимый от интерфейса движок категорий, нормализации данных, оценки критических проблем и сравнения отметок двух сторон.

- `voltcheck-all.html` — личный осмотр перед покупкой. Выберите категорию, заполните чек-лист и скачайте текстовый отчёт. Данные живут только в `sessionStorage` вкладки. Отсутствие отметки не считается исправностью.
- `voltpassport.html?demo=1&category=furniture` — демонстрация **заявлений продавца** и **самостоятельной проверки покупателя**. Сравнение выявляет расхождения и отдельно отмечает критические пункты.
- Для `smartphone` сохранена совместимость со старым `voltcheck.html` и его идентификаторами проверок.
- Переход с VoltPassport в VoltCheck Universal сохраняет идентификатор демо-сессии; после возврата в той же вкладке покупательские отметки могут переноситься в паспорт.
- Можно скачать `.txt` отчёт о сравнении. Это **личный отчёт**, не акт экспертизы и не сертификат.

## Важные ограничения

- В **реальных объявлениях** VoltPassport по-прежнему поддерживает только смартфоны. Другие категории показываются только в демо и самостоятельном VoltCheck Universal. Не меняйте `ads` и `ad_passports` до получения фактической рабочей схемы Supabase и независимого теста RLS.
- `supabase/voltpassport_schema_draft.sql` — **неприменённый черновик**, только для смартфонов. В данном PR не выполняются SQL-операции, публикация на Netlify и изменения в `main`.
- Данные паспорта продавца — его заявления, **не подтверждены VoltStore**. Покупательские ответы остаются в своей вкладке. Никакой автоматической проверки IMEI, оценки подлинности, гарантированной сделки, рейтинга доверия или синхронизации между устройствами нет.
- Не публикуйте IMEI, паспортные данные, контакты и другую личную информацию в заметках. Проверка на наличие таких данных в произвольном тексте технически не гарантируется.
- Отчёты, сохранённые из браузера, могут быть изменены получателем; не используйте их как доказательство независимой диагностики.
- Категории и подсказки требуют проверки профильными специалистами перед позиционированием как профессиональный осмотр.

## Как открыть и проверить

Локально через любой статический сервер:

```
python -m http.server 8000
```

- `http://localhost:8000/voltcheck-all.html?category=furniture`
- `http://localhost:8000/voltpassport.html?demo=1&category=bicycle`
- `http://localhost:8000/voltpassport.html?demo=1&category=laptop`
- `http://localhost:8000/voltpassport.html?demo=1&category=smartphone`

Для встраивания на сайт необходимы файлы `passport-core.js`, `passport-app.js`, `voltpassport.css`, `voltpassport.html`, `voltcheck-all.*`. Демо-режим паспорта не обращается к базе, но HTML пока подключает Supabase CDN и `config.js` для реального режима — в локальном превью отсутствие этих файлов не должно выдавать демо за опубликованный паспорт.

## Проверки

```
node --test tests/*.test.cjs
node --check passport-core.js
node --check passport-app.js
node --check voltcheck-all.js
```

Браузерные E2E-проверки в рабочем окружении автора могут блокироваться `ERR_BLOCKED_BY_ADMINISTRATOR`; при этом их нельзя считать выполненными. Перед публикацией следует провести ручной smoke на Chrome Desktop и мобильном устройстве.

## Безопасный путь к универсальному маркетплейсу

1. Получить точную структуру действующей базы (`ads`, `auth`, `profiles` и политики доступа).
2. Решить, какие категории реально поддерживаются в объявлениях и модерации; не смешивать цены, размеры и атрибуты в одной строке без схемы.
3. Спроектировать миграции для дополнительных категорий, валидацию JSON по категории, права продавца, логи редактирования паспортов.
4. На тестовой БД проверить RLS из ролей anon, buyer, owner, another seller, banned seller и admin.
5. Проверить соответствие хранения персональных данных требованиям Казахстана.
6. Только после этого предлагать выкладку и интеграцию с реальными объявлениями.
