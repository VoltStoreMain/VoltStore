# VoltMarket Beta — единый путь выбора и проверки товара

Ветка: feature/voltmarket-unified-flow (основана на PR #4 → PR #3 → PR #2).
Статус: тестовый автономный интерфейс. Не является открытым универсальным маркетплейсом с реальными продавцами.

## Пользовательский сценарий

1. На главной странице откройте VoltMarket.
2. В market.html выберите категорию (смартфоны, ноутбуки, мебель, велосипеды). Работают поиск, фильтры цены, города, состояния и один специфический фильтр категории (бренд / тип).
3. В карточке показаны характеристики демо-примера или локального черновика, сведения о состоянии **со слов условного продавца**. Незаполненное явно неизвестно.
4. VoltPassport Demo по ссылке из VoltMarket получает ID, категорию, модель, цену и заявленные состояния **именно этой демо-позиции**. Покупатель сравнивает их со своей проверкой. Это не сертификат.
5. VoltGuide получает категорию, модель, цену и ID и даёт бесплатные правила проверки. ГЕНЕРАТИВНАЯ модель пока отключена.
6. VoltCheck Universal позволяет отметить осмотр в sessionStorage той же вкладки. Возврат в VoltGuide/VoltPassport в этой вкладке позволяет использовать результаты.
7. На карточке можно сохранить личный план как TXT. Нет оплаты и бронирования.

## Сценарий продавца

На странице market.html#draft пользователь может создать локальный черновик с категорией, названием, ценой, городом, состоянием, описанием и тремя подходящими характеристиками.

- Черновики хранятся в localStorage только в браузере (не более 30), другим людям не видны.
- Публикация, серверная запись, переписки и реальная оплата отсутствуют. Фото, контакты и документы не собираются.
- В карточке локального черновика владелец может отметить статусы 11 категорийных проверок (исправно / дефект / не знаю). Эти заявления сохраняются только в этом браузере и подхватываются связанным VoltPassport Demo.
- Черновик можно удалить; созданный паспорт не является подтверждённым паспортом реального продавца.
- Нет фиктивных продавцов, вымышленных сделок или искусственно сгенерированных отзывов.

## Архитектура

- market-core.js: четыре категории, допустимые характеристики, нормализация демонстрационных записей и черновиков, фильтры, маршруты в другие модули. Без сетевых API.
- market.html, market.css, market.js: адаптивная витрина, навигация, карточки, локальные черновики.
- passport-app.js: в режиме demo=1&ad=... читает данные демо-позиции или локального черновика, чтобы не показывать паспорт постороннего товара. Принятый факт проверки по-прежнему определяется только собственными отметками покупателя.
- app.js и live.js: настоящая регистрация и размещение смартфонных объявлений остаются без изменений.
- VoltGuide: серверный генеративный режим из PR #4 отключён по умолчанию; плата за AI не начисляется.

## Что нужно до реального универсального запуска

P0:
1. Получить настоящую схему и регион Supabase, подтвердить соответствие локальным требованиям обработки персональных данных и правила RLS.
2. Спроектировать таблицы универсальных категорий, валидируемые JSONB-атрибуты, роли владельца и модератора, серверную проверку. Не переносить поля mem/bat на мебель.
3. Безопасно мигрировать старые объявления. Публикация новых объявлений должна проходить через модерацию, проверенные Storage policies, защиту владельца и ограничения числа загрузок.
4. Вести историю изменений паспорта и ревизии при существенном изменении заявления продавца.
5. Проверить анонимного и авторизованного пользователя, владельца, чужого продавца и модератора; отдельно тесты проданных и снятых товаров.
6. Полный мобильный E2E; реальное UX-тестирование и корректная политика несуществующих предложений.
7. До включения настоящего AI: тарифы и лимиты расходов, ограничение количества запросов на пользователя, логирование и защита персональных данных.

P1: полноценный публичный поиск и SEO после запуска реальных объявлений, фотографии, дополнительные фильтры.

P2: новые категории, партнёры, доставочные интеграции и платёжные процессы после доказательства спроса.

## Проверка

    node --check market-core.js
    node --check market.js
    node --test tests/*.test.cjs tests/*.test.mjs

Страница VoltMarket помечена noindex, чтобы демонстрационные предложения не индексировались как реальные. Для ручного preview используйте локальный статический HTTP-сервер. Не объединяйте с main до проверки рабочей базы и end-to-end сценариев.
